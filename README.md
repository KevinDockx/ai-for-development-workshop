# AI for Development Workshop

This is a full-day, hands-on workshop on using AI for software development, with a focus on GitHub Copilot. Instead of a clean demo project, you'll work in ClaimHub, a .NET 10 brownfield back-office application for Scheldt Assurance, a fictional insurer. ClaimHub is deliberately imperfect, which means it looks a lot more like the code most of us work on every day, and it gives the AI plenty of chances to get things wrong.

Throughout the day, you'll improve the application and make the repository easier and safer for AI to work in. We'll start by exploring the codebase and building AI-ready context. From there, we'll look at instructions, agents, skills, and MCP, and at the security questions that come with them. You'll then put all of that to work on bug fixing, technical debt, new features, and tests. Along the way, you'll check what the AI produces, because in a codebase like this one, it won't always get things right. In case you're wondering: the code, people, policies, data, and credentials in this repository are all synthetic.
