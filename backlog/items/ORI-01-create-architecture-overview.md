## Story or problem statement

Create a one-page overview that helps someone find their way around ClaimHub. Include the main projects, their responsibilities, important dependencies, and a Mermaid diagram. AI can help you explore, but the finished overview must reflect the repository you actually inspected.

## Acceptance criteria

- [ ] The overview names every solution project and its responsibility.
- [ ] A Mermaid diagram shows the main runtime and project relationships.
- [ ] Every relationship in the diagram has been checked against the solution.
- [ ] Uncertainty or an intentional inconsistency is called out rather than guessed away.

## Notes

Keep this to one useful page. The next person should be able to use it to find their way around ClaimHub.

## AI approach hint

Ask AI for an initial map, then verify it by following project references and startup paths yourself.
