## Story or problem statement

Get the API, Admin portal, Worker, and tests running from a clean checkout. Follow the README first, record every instruction that is wrong or missing, and keep the evidence for the later documentation work.

## Acceptance criteria

- [ ] The solution builds and its tests run.
- [ ] The API, Admin portal, and Worker each start successfully.
- [ ] README commands, ports, project names, and prerequisites have been checked.
- [ ] Every mismatch is recorded with the command or observation that disproved it.

## Notes

Do not quietly work around bad documentation. The list of mismatches is part of the outcome.

## AI approach hint

Ask AI to turn failures into a verification checklist, but rerun the commands yourself.
