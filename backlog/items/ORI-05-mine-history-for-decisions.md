## Story or problem statement

Use the git history and meeting notes to identify the decisions that shaped ClaimHub. Record the decision, its evidence, whether the code follows it, and any contradiction that still needs resolving.

## Acceptance criteria

- [ ] Relevant commits and meeting notes have been reviewed.
- [ ] Each recorded decision cites its repository evidence.
- [ ] Accepted, rejected, and superseded decisions are distinguished.
- [ ] At least one mismatch between a decision and the current code is recorded.

## Notes

The `Meeting notes` folder uses inconsistent dates, so do not assume file ordering tells the whole story.

## AI approach hint

Let AI cluster commits and notes by topic, then check the original evidence before accepting a conclusion.
