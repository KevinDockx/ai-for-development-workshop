## Story or problem statement

Restructure the repository so people and AI can find current architecture, domain, development, specification, and script content without sorting through competing legacy folders.

## Acceptance criteria

- [ ] Current documentation has clear homes for architecture, domain, development, ADRs, and specifications.
- [ ] Authoritative scripts are easy to discover.
- [ ] Useful legacy content is promoted before obsolete folders are retired.
- [ ] Links and repository instructions point to the new locations.
- [ ] The solution still builds and tests after the move.

## Notes

Legacy folders contain a mix of truth and stale guidance. Preserve evidence while making authority clear.

## AI approach hint

Have AI propose a move plan with source and destination pairs, then review it before allowing any deletion.
